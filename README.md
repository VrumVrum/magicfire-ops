# magicfire-ops

Autonomous SEO operations for **[magicfire.ro](https://magicfire.ro)** — artificii și efecte pirotehnice, Iași.

Public so GitHub Actions minutes are free. A daily workflow pulls Google Search Console data and runs a mobile-first health check on the live site, committing results to `data/` where the operating routine reads them.

- `CLAUDE.md` — the operating system: what the business is, what moves the needle, the hard rules.
- `data/` — machine-written: `gsc.json`, `site.json`. No personal or customer data.
- `ledger/` — decisions, KPIs and scored outcomes.
